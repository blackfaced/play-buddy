# 钟楼空间与挑战提示修订

2026-10-09 用户反馈：挑战模式不应显示“残画”“桌边的抽屉可以拉动”等热点文字，也不应主动提示“观察白色刻线，记住位置”；钟楼不能靠底部三个标签切换，需要场景里的门、楼梯和更多实际探索。

## 已实现方向

- 钟机阁楼的实体木门通向工作间，地板楼梯通向配重井；两处提供画内返回通道，移除原三标签主导航。
- 窗板后显露检修洞，通向配重背后的夹层。可先看到被压住的齿轮与检修架画片，回井边安装摇柄抬起配重，再回夹层取物。
- 保留齿轮试转、拼画、凸轮之间的原有推理与答案；新鲜探索与旧版迁移分开，旧的单独齿轮/画片获取状态和已解锁钟门不丢失。
- 挑战模式隐藏叠加物件名称、原生热点提示、鼠标探索发光，以及自动教玩家观察、记忆、联想的文案。简单与标准模式维持原提示。
- 保留场景内真实文字和图案、必要操作方法、已选物件反馈、可访问名称和键盘焦点。挑战试转后只显示中性结果。

## 验证

新增挑战模式提示回归、钟楼实体通路验证，以及独立旧存档/全模式通关事件验证；包含模式切换后不残留标准模式提示、错误排列、返回/重复拿取/取消、先取画片后抬重、跨位置携带手柄等情况。

实际场景 SVG 已栅格化检查门、楼梯、洞口和抬重前后的可见变化。此项不是浏览器截图；真实浏览器布局、设备触控和焦点样式仍未实机验证。

最终验证：npm run verify:escape 全量通过；生产构建、改动模块 ESLint 通过。最后一处配重井正面齿轮过早消失的绘图修正后，重新通过空间/独立通路/旧存档/挑战提示四项验证、定向 lint 与生产构建。构建仍有已知 chunk 体积警告。
