# 纸偶舞台与成功反馈修订

## 用户反馈

2026-10-09：纸偶/滑杆变化不清楚，试灯滑杆似乎只能移动到中间和末端；机关与操作需要上下滚动，体验混乱。解谜成功后缺少明确动画反馈。

## 修改范围

- 移除独立试灯演示面板与冗余 demo 滑杆（存档字段兼容保留）。纸偶沿灯束的真实位置、方向和投影缩放同域显示。
- 舞台采用原生 dialog 专用近景，避免关卡标题、工具栏和冗余卡片占据可用视口。一处舞台包含纸偶、投影、三条距离滑杆、旋转和整体演出灯杆。
- 可直接在图上点选/交換或拖动纸偶；按钮为备用。所有距离档位覆盖 1→2→3→1。旧浏览器端点问题未复现，不声称已确认其浏览器原因。
- 第一次 Escape 取消拿起物件，再次 Escape 退出近景；返回放映廊并恢复入口焦点。小视口或放大文字时保留滚动，不能裁切操作。
- 显式完成的机关给出中性动画/已完成状态，挑战模式也保留；不提示答案或下一步，不因排列碰巧正确就提前宣布成功。
- 成功事件由实际接受操作触发，载入、重访、切难度、撤回不伪造成功。防止失效的异步回调修改进度或输出成功文案。减少动态效果偏好得到尊重。

## 验证边界

回归包含实际组件事件、存档和中断生命周期，以及真实 SVG 静态像素比较。按样式静态估算，专用近景可容纳常规 1366×768 桌面和 390×844 手机视口；真实浏览器布局、原生焦点捕获与触屏仍未实机验证，因此不能将估算称为浏览器通过。
