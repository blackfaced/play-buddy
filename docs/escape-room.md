# 星光号：航海员的钥匙

原创中文静态密室，入口 `/escape`，在游戏大厅登记为 `play`。四个船舱视角，物件近景、道具组合、自动线索手记、三级提示、可关闭音效。所有 SVG 插画为项目原创，无运行时服务、外部素材或新增依赖。

## 操作

点击场景物件探索。点击背包道具选中，再到相应场景使用。依次点击磁铁与细绳即可组合（顺序不限）。无游戏倒计时与错误惩罚。全局 HealthGate 保持有效；休息或时长上限出现时，近景弹窗关闭、游戏区域 inert，解除限制后继续原近景。

进度独立保存在 `play-buddy:escape:starlight:v1`，包括持有物品、已解机关、图环朝向与发现的线索。使用版本及依赖校验，错误存档安全回到起点。重开需要二次确认，只影响本关。

## 解法（剧透）

1. 查看九面信号旗：锚 4，月 2，星 3。依抽屉刻印顺序输入 `423`，得到磁铁、日光徽章。
2. 取航海桌软布，选中后擦净海图。按编号 0→5 读取五段航向 `↑→↓→↑`，打开方向锁拿到细绳。步骤 1 与 2 可并行。
3. 背包依次点磁铁、细绳，组合系绳磁铁。
4. 选中系绳磁铁，从船模细缝吸住铁环，取月光徽章。
5. 圆环匣嵌入两个徽章，按船模旁明信片复原灯塔。外、中、内环从初始状态分别顺时针转 3、2、1 次；按中央锁扣，获得钥匙。
6. 选中钥匙，打开甲板舱门。

错误尝试不扣除物品。重复拾取、使用和点击是幂等的。两个徽章在嵌入后从背包移出；其他工具保留。
