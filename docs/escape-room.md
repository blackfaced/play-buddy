# 星光号：航海员的钥匙

原创中文静态密室，入口 `/escape`，在游戏大厅登记为 `play`。四个船舱视角，物件近景、道具组合、自动线索手记、三级提示、可关闭音效。所有 SVG 插画为项目原创，无运行时服务、外部素材或新增运行时依赖。

## 操作

点击场景物件探索。点击背包道具选中，再到相应场景使用。依次点击磁铁与细绳即可组合（顺序不限）。无游戏倒计时与错误惩罚。全局 HealthGate 保持有效；休息或时长上限出现时，近景弹窗关闭、游戏区域 inert，解除限制后继续原近景。

进度独立保存在 `play-buddy:escape:starlight:v1`，包括持有物品、已解机关、图环朝向与发现的线索。存档键保留兼容，数据版本升级为 3。版本 1 的道具、已解锁机关与结局保留；已经看过旧明信片或打开圆环匣的玩家保留灯塔参考图，其他旧存档可随时完成木条画。使用版本及依赖校验，错误存档安全回到起点。独立船舱组件的重开需要二次确认；完整冒险入口不提供船舱重开，后两间房可以单独重新探索。

## 解法（剧透）

1. 查看递推算图。直角三角形每行增加一格，第一列是起始数，其余每格 = 左边 + 左上方。完整五行：`1`；`2,3`；`3,5,8`；`4,7,12,20`；`1,5,12,24,44`。底行从 44 向左倒推。星、月、锚给出密码 `375`，打开抽屉得到磁铁、日光徽章。
2. 取航海桌软布，选中后擦净海图。按编号 0→5 读取五段航向 `↑→↓→↑`，打开方向锁拿到细绳。步骤 1 与 2 可并行。
3. 背包依次点磁铁、细绳，组合系绳磁铁。
4. 选中系绳磁铁，从船模细缝吸住铁环，取月光徽章。
5. 船模旁木条画：每根木条等差递增，下一个数对应槽位。`3,6,9→12`；`2,4,6→8`；`1,6,11→16`；`1,4,7→10`；`2,6,10→14`。先点击木条，再点槽位，可用触屏或 Tab/回车。木条可任意放置、拿下、替换，放置会保存。全部摆好后点击“确认整幅画”，整幅正确才获得灯塔参考图。
6. 圆环匣嵌入两个徽章，按木条画复原灯塔。外、中、内环从初始状态分别顺时针转 3、2、1 次；按中央锁扣，获得钥匙。
7. 选中钥匙，打开甲板舱门。

错误尝试不扣除物品。重复拾取、使用和点击是幂等的。木条画、抽屉、海图分支可并行；最终圆环匣要求木条画已修复。两个徽章在嵌入后从背包移出；其他工具保留。

## 验证

- `npm run verify:escape`：纯 reducer 全程、前置依赖、两条并行支线、重复操作、递推唯一性、木条对应关系、v1/v2 存档迁移、重开。
- `npm run build`
- `node --test e2e/escape-room.test.js`：构建产物的全流程、错误输入、刷新恢复、道具组合、图环、船舱结局、进入导航室、后两间房重开确认、手机布局、弹窗 Escape、渐进提示。可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已安装 Chromium。
- `npx eslint src/escape scripts/verify-escape.ts e2e/escape-room.test.js`

实现：`logic.ts` 纯状态机与递推规则，`MathProps.tsx` 数字道具近景，`EscapeRoom.tsx` 交互，`RoomArt.tsx` 原创插画，`escape.css` 作用域样式。不改主 store 或生成式 UI 组件。

## 完整三场景版

`/escape` 现在由 `adventure/Adventure.tsx` 承载：完成原船舱后进入导航室，再探索甲板储物舱，最后到观星甲板。新增近景藏物、移动遮挡物、工具使用、水深保险柜、投影仪、5×5 逻辑图与绞盘机关。导航室和储物舱进度独立保存在 `play-buddy:escape:expedition:v1`；可返回船舱，重开后两间房不会清空船舱进度。

标准模式默认；简单模式有自动引导；挑战模式隐藏提示入口与物件标记，保留键盘可达标签。三种模式共用答案且切换保留进度。木条自由摆放、引导和存档迁移详见 [escape-v2.2.md](escape-v2.2.md)。

`verify:escape` 还覆盖完整冒险状态机、逻辑图唯一解、房间回退、隐藏物件和工具流程、独立章节重开、实际 React 交互及物件标签 CSS 回归。新增依赖 `react-test-renderer` 只用于开发测试。浏览器 e2e 已按当前入口更新，但本轮环境无法启动浏览器，未声称浏览器通过。
